ИИ перестаёт перечитывать весь проект в каждой сессии, и лимит уходит медленнее

10 минут, с компьютера

Компьютер
ИИ

Зачем он нужен

  • Без графаВ каждой новой сессии ClaudeCodex заново открывает файлы проекта, и на это уходит лимит
  • Карта проектаGraphify один раз разбирает твои файлы и связи между ними и сохраняет граф
  • Дальше по картеИИ находит нужное в графе и открывает только файлы под твою задачу
  • Код остаётся у тебяGraphify разбирает код на твоём компьютере, наружу ничего не уходит
Graphify бесплатный, код открыт на GitHub. Чем больше проект, тем заметнее экономия: маленький проект и так целиком помещается в контекст

Что понадобится

  • Claude Code. Он входит в тарифы Pro, Max, Ultra, Team и Enterprise, на бесплатном его нет
  • Codex. Он входит в ChatGPT, даже в бесплатный
  • Компьютер на Windows или Mac и твой проект в папке: код, заметки или документы
  • Менеджер uv, через него ставится Graphify. Как поставить, в шаге 1

Шаг 1 из 4

Поставь uv

  1. Открой PowerShell: нажми «Пуск», напиши PowerShell и открой его
  2. Открой Терминал: нажми Cmd+Пробел, напиши Терминал и открой его
  3. Вставь команду и нажми Enter
winget install astral-sh.uvcurl -LsSf https://astral.sh/uv/install.sh | sh
Потом закрой окно терминала и открой заново

Проверь

uv --version
Придёт строка: uv и номер версии. Python отдельно ставить не нужно, uv скачает подходящий сам

Шаг 2 из 4

Поставь Graphify

В том же окне по очереди две команды. Первая скачивает Graphify, вторая подключает его к Claude CodeCodex

uv tool install graphifyy
graphify installgraphify install --platform codex
В названии пакета две «y»: graphifyy. Это официальный. Другие пакеты с похожими названиями к Graphify отношения не имеют
Если терминал пишет, что graphify не найден, отправь uv tool update-shell и открой терминал заново

Шаг 3 из 4

Построй граф

  1. Открой приложение Claude, вкладку Code. Под полем ввода выбери Local, затем Open folder… и папку проекта
  2. Открой терминал в папке проекта и набери codex. Или открой Codex в приложении ChatGPT на компьютере и выбери папку проекта
  3. Отправь команду
/graphify .$graphify .
В проекте появится папка graphify-out. Открой в ней graph.html в браузере: это весь проект картой, по узлам можно нажимать и искать
Рядом лежит GRAPH_REPORT.md: главные узлы проекта и неочевидные связи между ними

Шаг 4 из 4

Работай как обычно

Ставь задачи так же, как раньше. ClaudeCodex сам заглядывает в граф. А если хочешь, спроси граф напрямую

/graphify query "что связывает авторизацию с базой данных?"$graphify query "что связывает авторизацию с базой данных?"

Чтобы граф не устаревал

graphify hook install
Отправь в терминале в папке проекта. Граф будет сам обновляться после каждого коммита Git
Без Git обнови граф вручную: /graphify . --update$graphify . --update, он пересоберёт только изменённые файлы

Честно про экономию

На graphify.com пользователь пишет про токенов в 79 раз меньше. Это отзыв, а не замер, и у тебя цифра будет своя
Сам Graphify бесплатный. Платное у них только облако Graphify Cloud, для обычной работы оно не нужно

Готово. Теперь ClaudeCodex ходит по карте проекта, а не перечитывает его целиком

Пишет, что uv не найден

Закрой окно терминала и открой заново. Если не помогло, поставь uv ещё раз, как в шаге 1

Нет вкладки Code или Claude просит сменить тариф

Claude Code есть в тарифах Pro, Max, Ultra, Team и Enterprise. На бесплатном тарифе его нет

Claude не знает команду /graphify

Отправь /reload-skills. Если не помогло, снова выполни в терминале graphify install

Codex не понимает $graphify

Выполни в терминале graphify install --platform codex и перезапусти Codex. В Codex команда пишется через $, а не через /

Поставился не тот пакет

Официальный пакет пишется с двумя «y»: graphifyy. Код и инструкции лежат на github.com/Graphify-Labs/graphify
